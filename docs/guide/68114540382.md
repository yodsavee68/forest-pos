### การส่งข้อมูล (API Response)
ควรส่ง JSON ที่ Frontend เอาไปวนลูปสร้าง UI ได้ง่าย เช่น:
```json
{
  "id": 1,
  "name": "Pad Kra Pao",
  "price": 50,
  "category_id": 1,
  "modifier_groups": [
    {
      "name": "Spiciness",
      "min_select": 1,
      "max_select": 1,
      "options": [
        { "id": 10, "name": "Medium", "price_adjustment": 0 }
      ]
    }
  ]
}
```


### Global Cache Utility
ระบบมี `InMemoryCache` ให้ใช้งาน (e.g., Caching Product List)
```python
from app.core.cache import cache

# Set Value (TTL 5 mins default)
cache.set("all_products", products_list_json, ttl_seconds=300)

# Get Value
cached_data = cache.get("all_products")
if cached_data:
    return cached_data
```

## 3. การใช้งาน Git (Git Workflow)

1. **สร้าง Branch ใหม่:** ตั้งชื่อว่า `dev-<ชื่อเล่น>`
   ```bash
   git checkout -b dev-yourname
   ```
2. **ก่อนเริ่มงาน:** ดึงโค้ดล่าสุดจาก `main` เสมอ
   ```bash
   git checkout main
   git pull origin main
   git checkout dev-yourname
   git merge main
   ```
3. **ส่งงาน (Pull Request):**
   - Push branch ขึ้น Server
     ```bash
     git push origin dev-yourname
     ```
   - เข้า Web GitHub ไปกด New Pull Request
   - **สำคัญ:** แจ้ง Leader (หรือเพื่อนในทีม) ให้มาตรวจโค้ดทุกครั้งก่อนรวม
