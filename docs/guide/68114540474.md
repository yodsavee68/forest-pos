**Role:** Customer / ส่วนของ Order  
**หน้าที่หลัก:** พัฒนาระบบสร้างและดูข้อมูลออเดอร์สำหรับลูกค้า

## 1. สิ่งที่ต้องทำ (Checklist)

### Backend (FastAPI)
- [ ] **Database Model:** ตรวจสอบ Table `Order`, `OrderItem`, `OrderItemSelection` ใน `server/app/models/order.py`
- [ ] **Pydantic Schema:** สร้าง Schema สำหรับรับ-ส่งข้อมูลออเดอร์
    - `OrderCreate` (รับ `session_id`, `items`: list of `{product_id, quantity, modifiers, note}`)
    - `OrderResponse`
- [ ] **API Router:** สร้างไฟล์ `server/app/api/orders.py`
- [ ] **Implement Routes:**
    1. `POST /api/orders`
       - รับ `session_id` และรายการอาหาร
       - คำนวณราคารวม (รวม Modifier Price)
       - สร้าง `Order` และ `KitchenBatch` (Round 1)
       - บันทึก `OrderItem` และ `OrderItemSelection`
    2. `GET /api/orders/{order_id}`
       - ดึงข้อมูลสถานะออเดอร์ และรายการอาหารที่สั่งไป

### Frontend (Next.js)
- [ ] **Cart/Checkout Page:** หน้าสรุปรายการอาหารและปุ่ม "ยืนยันการสั่ง"
- [ ] **Order Status Page:** หน้าแสดงสถานะ (รอเสิร์ฟ/เสิร์ฟแล้ว) โดยดึงข้อมูลจาก `GET /api/orders/{order_id}`

## 2. คำแนะนำทางเทคนิค (Technical Guide)

### Backend Flow
1. **Model**:
   ```python
   # server/app/models/order.py
   # (ดูไฟล์จริงที่สร้างไว้แล้ว)
   # Order มี session_id, order_number, grand_total
   # OrderItem มี unit_price, total_price, modifiers (relation)
   ```
2. **Endpoint**:
   - ใช้ `APIRouter` จาก FastAPI
   - อย่าลืม Register router ที่ `server/app/main.py`

### Frontend Flow
- ใช้ `fetch` หรือ `axios` ยิงไปที่ `http://localhost:8000/api/orders`
- หน้า checkout ควรส่ง JSON body ประมาณ:
  ```json
  {
    "session_id": 1,
    "items": [
      {
        "product_id": 1,
        "quantity": 2,
        "note": "ไม่เผ็ด",
        "modifiers": [
          { "modifier_option_id": 5, "price_snapshot": 10.0 }
        ]
      }
    ]
  }
  ```

### Global Cache Utility
ระบบมี `InMemoryCache` ให้ใช้งาน (e.g., เก็บ OTP, Temporary Data)
```python
from app.core.cache import cache

# Set Value (TTL 5 mins default)
cache.set("order_101_temp", {"status": "pending"}, ttl_seconds=300)

# Get Value
data = cache.get("order_101_temp")
if data:
    print(data)
```

## 3. การใช้งาน Git (Git Workflow)

1. **สร้าง Branch ใหม่:** ตั้งชื่อว่า `dev-<ชื่อเล่น>`
   ```bash
   git checkout -b dev-yourname
   ```
2. **ก่อนเริ่มงาน:** ดึงโค้ดล่าสุดจาก `main` เสมอ
   ```bash
   git checkout main
   git pull origin main
   git checkout dev-yourname
   git merge main
   ```
3. **ส่งงาน (Pull Request):**
   - Push branch ขึ้น Server
     ```bash
     git push origin dev-yourname
     ```
   - เข้า Web GitHub ไปกด New Pull Request
   - **สำคัญ:** แจ้ง Leader (หรือเพื่อนในทีม) ให้มาตรวจโค้ดทุกครั้งก่อนรวม
