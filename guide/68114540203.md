## 1. สิ่งที่ต้องทำ (Checklist)

### Backend (FastAPI)
- [ ] **Implementation Route:** สร้างหรือแก้ไขไฟล์ `server/app/api/products.py` และ `tables.py`
    1. `POST /api/products`
       - รับข้อมูลสินค้า (ชื่อ, ราคา, รูปภาพ, category)
       - บันทึกลง Database
       - (Optional: Upload รูปภาพ)
    2. `POST /api/tables/open`
       - รับเลขโต๊ะ (Table No)
       - Generate Session ID หรือ Token สำหรับโต๊ะนั้น
       - สร้าง QR Code Link (ส่งกลับเป็น URL หรือ Base64 image)

### Frontend (Next.js)
- [ ] **Admin Menu Management:** หน้าฟอร์มสำหรับเพิ่ม/แก้ไขอาหาร
- [ ] **Table Management:** หน้าสำหรับกดเปิดโต๊ะ และพิมพ์ QR Code

## 2. คำแนะนำทางเทคนิค (Technical Guide)

### Table Session
การเปิดโต๊ะควรสร้าง Session ใน Database เพื่อผูกกับออเดอร์ในอนาคต
```python
# server/app/models/table.py (Example)
class TableSession(Base):
    id = Column(Integer, primary_key=True)
    table_no = Column(String)
    token = Column(String) # Unique token for QR Code
    is_active = Column(Boolean, default=True)
```

### QR Code Library (Frontend)
ใช้ `qrcode.react` หรือ library อื่นๆ ใน Next.js เพื่อ render QR Code จาก URL ที่ได้จาก Backend
```bash
npm install qrcode.react
```
