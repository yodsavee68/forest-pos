# งานของคุณ: นายณัฐวุฒิ ตูมหอม (68114540203)

**Role:** Admin / จัดการเมนูและเปิดโต๊ะ  
**หน้าที่หลัก:** สร้างเมนูอาหารใหม่ และ Generate QR Code สำหรับเปิดโต๊ะให้ลูกค้า

---

## 1. สิ่งที่ต้องทำ (Checklist)

### Backend (FastAPI)
- [ ] **Implementation Route:** สร้างหรือแก้ไขไฟล์ `server/app/api/products.py` และ `tables.py`
    1. `POST /api/products`
       - รับข้อมูลสินค้า (ชื่อ, ราคา, รูปภาพ, category_id)
       - รับ Modifier Groups ที่เกี่ยวข้อง (ProductModifierLink)
       - บันทึกลง Database
    2. `POST /api/tables/open`
       - รับเลขโต๊ะ (Table No)
       - สร้าง `TableSession` ใหม่
       - Generate `qr_uuid` และ `access_code`

### Frontend (Next.js)
- [ ] **Admin Menu Management:** หน้าฟอร์มสำหรับเพิ่ม/แก้ไขอาหาร
- [ ] **Table Management:** หน้าสำหรับกดเปิดโต๊ะ และพิมพ์ QR Code

---

## 2. คำแนะนำทางเทคนิค (Technical Guide)

### Table Session
การเปิดโต๊ะควรสร้าง Session ใน Database (ดู `server/app/models/table.py`)
Model `TableSession` มี field `access_code` สำหรับลูกค้าใช้ login หรือ verify

### QR Code Library (Frontend)
ใช้ `qrcode.react` หรือ library อื่นๆ ใน Next.js เพื่อ render QR Code จาก URL ที่ได้จาก Backend
```bash
npm install qrcode.react
```

## 3. การใช้งาน Git (Git Workflow)

1. **สร้าง Branch ใหม่:** ตั้งชื่อว่า `dev-<ชื่อเล่น>`
   ```bash
   git checkout -b dev-yourname
   ```
2. **ก่อนเริ่มงาน:** ดึงโค้ดล่าสุดจาก `main` เสมอ
   ```bash
   git checkout main
   git pull origin main
   git checkout dev-yourname
   git merge main
   ```
3. **ส่งงาน (Pull Request):**
   - Push branch ขึ้น Server
     ```bash
     git push origin dev-yourname
     ```
   - เข้า Web GitHub ไปกด New Pull Request
   - **สำคัญ:** แจ้ง Leader (หรือเพื่อนในทีม) ให้มาตรวจโค้ดทุกครั้งก่อนรวม
