# งานของคุณ: นายปรีชา แสงแก้ว (68114540382)

**Role:** Customer / แสดงรายการอาหารและ option  
**หน้าที่หลัก:** ดึงข้อมูลเมนูอาหารมาแสดงให้ลูกค้าเห็น รวมถึงตัวเลือกต่างๆ (เช่น หวานน้อย, เพิ่มไข่ดาว)

---

## 1. สิ่งที่ต้องทำ (Checklist)

### Backend (FastAPI)
- [ ] **Database Model:** ออกแบบ Table `Product` และ `ProductOption` ใน `server/app/models/product.py`
- [ ] **Implement Routes:**
    1. `GET /api/products`
       - ดึงรายการสินค้าทั้งหมด (อาจจะ filter ตาม category ได้)
       - ต้อง Join กับ Option ให้เรียบร้อย หรือดึงแยก
    2. `GET /api/products/{product_id}/options`
       - ดึงตัวเลือกของสินค้านั้นๆ (เช่น สินค้า: กะเพรา -> Option: ไข่ดาว, ไข่เจียว, ความเผ็ด)

### Frontend (Next.js)
- [ ] **Menu Page:** แสดงรายการอาหารแบบ Grid/List (รูปภาพ, ชื่อ, ราคา)
- [ ] **Product Detail Modal/Page:** พอกดที่อาหาร จะแสดง Popup ให้เลือก Option ก่อนกดลงตะกร้า

## 2. คำแนะนำทางเทคนิค (Technical Guide)

### Model Relationship
```python
# server/app/models/product.py
class Product(Base):
    # ...
    options = relationship("ProductOption", back_populates="product")

class ProductOption(Base):
    # ...
    product_id = Column(Integer, ForeignKey("products.id"))
    name = Column(String) # e.g. "Topping"
    choices = Column(JSON) # e.g. ["Fried Egg", "Omelet"]
```

### การส่งข้อมูล (API Response)
ควรส่ง JSON ที่ Frontend เอาไปวนลูปสร้าง UI ได้ง่าย เช่น:
```json
{
  "id": 1,
  "name": "Pad Kra Pao",
  "price": 50,
  "options": [
    { "name": "Spiciness", "choices": ["Mild", "Medium", "Spicy"] }
  ]
}
```
