## 2. คำแนะนำทางเทคนิค (Technical Guide)

### SQL Query for Stats
การหาเมนูขายดี ต้องใช้ `func.count` และ `group_by` ของ SQLAlchemy
```python
# ตัวอย่าง query คร่าวๆ
stmt = (
    select(Product.name, func.sum(OrderItem.quantity).label("total_sold"))
    .join(Product)
    .group_by(Product.id)
    .order_by(desc("total_sold"))
    .limit(5)
)
```

   ```bash
   git checkout -b dev-yourname
   ```
2. **ก่อนเริ่มงาน:** ดึงโค้ดล่าสุดจาก `main` เสมอ
   ```bash

   ```
3. **ส่งงาน (Pull Request):**
   - Push branch ขึ้น Server
     ```bash
     git push origin dev-yourname
     ```
