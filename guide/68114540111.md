# งานของคุณ: นายจารุกิตติ์ ใจงาม (68114540111)

**Role:** Admin / แสดงออเดอร์ที่เข้ามา  
**หน้าที่หลัก:** หน้าจอสำหรับครัว/พนักงานที่แสดงออเดอร์ทั้งหมดที่เข้ามาแบบ Real-time

---

## 1. สิ่งที่ต้องทำ (Checklist)

### Backend (FastAPI)
- [ ] **Socket.io Handler:** จัดการ event connection ใน `server/app/main.py` หรือแยกไฟล์
- [ ] **Implement Routes:**
    1. `GET /api/orders/active`
       - Query database หา `KitchenBatch` หรือ `OrderItem` ที่สถานะ *ไม่ใช่* `served`/`cancelled`
       - เรียงตามเวลา (มาก่อนอยู่ก่อน)
    2. `WS /socket.io/orders` (Socket Namespace)
       - จัดการ room หรือ broadcast เมื่อมีออเดอร์ใหม่เข้ามา

### Frontend (Next.js)
- [ ] **Kitchen Display System (KDS):** หน้าจอแสดงรายการออเดอร์
- [ ] **Real-time Listener:** ใช้ `socket.io-client` ดักจับ event `new_order` เพื่อแสดงออเดอร์ใหม่ทันทีโดยไม่ต้อง refresh หน้าจอ

### Frontend Socket Client
```typescript
// client/app/admin/orders/page.tsx
import { io } from "socket.io-client";
// ...
useEffect(() => {
  const socket = io("http://localhost:8000");
  socket.on("new_order", (order) => {
    setOrders((prev) => [...prev, order]);
  });
  return () => socket.disconnect();
}, []);
```

## 3. การใช้งาน Git (Git Workflow)

1. **สร้าง Branch ใหม่:** ตั้งชื่อว่า `dev-<ชื่อเล่น>`
   ```bash
   git checkout -b dev-yourname
   ```
2. **ก่อนเริ่มงาน:** ดึงโค้ดล่าสุดจาก `main` เสมอ
   ```bash
   git checkout main
   git pull origin main
   git checkout dev-yourname
   git merge main
   ```
3. **ส่งงาน (Pull Request):**
   - Push branch ขึ้น Server
     ```bash
     git push origin dev-yourname
     ```
   - เข้า Web GitHub ไปกด New Pull Request
   - **สำคัญ:** แจ้ง Leader (หรือเพื่อนในทีม) ให้มาตรวจโค้ดทุกครั้งก่อนรวม
