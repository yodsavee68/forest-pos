# งานของคุณ: นายยศวีร์ ศุภโชคธนาทรัพย์ (68114540474)

**Role:** Customer / ส่วนของ Order  
**หน้าที่หลัก:** พัฒนาระบบสร้างและดูข้อมูลออเดอร์สำหรับลูกค้า

---

## 1. สิ่งที่ต้องทำ (Checklist)

### Backend (FastAPI)
- [ ] **Database Model:** ออกแบบ Table `Order`, `OrderItem` ใน `server/app/models/order.py`
- [ ] **Pydantic Schema:** สร้าง Schema สำหรับรับ-ส่งข้อมูลออเดอร์ ใน `server/app/schemas/order.py`
    - `OrderCreate` (สำหรับรับข้อมูลตอนลูกค้าสั่ง)
    - `OrderResponse` (สำหรับส่งข้อมูลกลับ)
- [ ] **API Router:** สร้างไฟล์ `server/app/api/orders.py`
- [ ] **Implement Routes:**
    1. `POST /api/orders`
       - รับรายการอาหาร (Product ID, Quantity, Options)
       - คำนวณราคารวม
       - บันทึกลง Database
       - (Optional: Trigger Socket.io ไปบอก Admin/Kitchen)
    2. `GET /api/orders/{order_id}`
       - ดึงข้อมูลสถานะออเดอร์ และรายการอาหารที่สั่งไป

### Frontend (Next.js)
- [ ] **Cart/Checkout Page:** หน้าสรุปรายการอาหารและปุ่ม "ยืนยันการสั่ง"
- [ ] **Order Status Page:** หน้าแสดงสถานะ (รอเสิร์ฟ/เสิร์ฟแล้ว) โดยดึงข้อมูลจาก `GET /api/orders/{order_id}`

---

## 2. คำแนะนำทางเทคนิค (Technical Guide)

### Backend Flow
1. **Model**:
   ```python
   # server/app/models/order.py
   class Order(Base):
       __tablename__ = "orders"
       id = Column(Integer, primary_key=True)
       table_no = Column(String)
       total_price = Column(Float)
       status = Column(String) # pending, cooking, served, paid
       items = relationship("OrderItem", back_populates="order")
   ```
2. **Endpoint**:
   - ใช้ `APIRouter` จาก FastAPI
   - อย่าลืม Register router ที่ `server/app/main.py`

### Frontend Flow
- ใช้ `fetch` หรือ `axios` ยิงไปที่ `http://localhost:8000/api/orders`
- หน้า checkout ควรส่ง JSON body ประมาณ:
  ```json
  {
    "table_no": "A1",
    "items": [
      {"product_id": 1, "quantity": 2, "note": "ไม่เผ็ด"}
    ]
  }
  ```
